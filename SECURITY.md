# Security and responsible use

This repository is for learning defensive security in your own lab.

- Test only systems you own or have written permission to test. Do not point anything here at third-party targets.
- All sample data (IP addresses, domains, people, logs) is fictional. IP addresses use documentation ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) and domains use `example.*`.
- No real credentials are in this repository.
